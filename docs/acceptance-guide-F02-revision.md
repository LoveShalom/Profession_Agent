### AC-3 分类 + 投递定位展示 ✅/⬜

## 6. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 看不到删除按钮/类别列 | 旧生产构建（源码更新但没 rebuild） | 用 `start.bat`（已自动检测重建）或 `npm run app -- --rebuild`，再 Ctrl+F5 |
| `clean:synthetic` 报告命中脏数据 | 之前清理过但又造了新的 | 加 `--apply` 执行软删除 |
| 台账没有「类别」列 | 旧导出文件 | 重新 `npm run workspace:export` |
| 改 Excel 类别后同步没变化 | 单元格写的是不认识的字符串 → 被当作**自定义分类**保存（预期）；或文件未保存 | 确认保存；`--dry-run` 看报告 |
| 改 Excel 定位后没变化 | 写了不认识的值（只认 主投/副投/碰运气 或英文） | 用规范中文或英文值 |
| 同步把分类清空了 | 旧版本行为（已修） | 更新代码；当前区别处理"缺列"与"空单元格" |
| `db:backfill-category` 覆盖了手改 | 用了 `--force` | 默认不带 `--force` 即保护手改 |
| 分类/定位明显不对 | 规则派生只看关键词 | 详情页手改分类或定位（手改不会被自动覆盖） |
| 台账同步报"受保护删行" | 你在 Excel 删了一行 | 设计如此：删行不删库；删岗位请用界面「删除」 |
| 迁移数不是 9 | 迁移没跑或记录缺失 | `node scripts/migrate.mjs`；`npm run preflight` 会提示 |
