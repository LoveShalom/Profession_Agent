## 3. 手工验收（15 分钟，逐条打勾）

启动：`npm run dev` → 打开 http://localhost:3000/jobs/board

### AC-1 看板拖拽流转 ✅/⬜

1. 把「星辰科技（待投递）」拖到 **已投递** 列
2. 期望：卡片立刻出现在已投递列；右上角绿色提示；刷新后仍在

### AC-2 跨步前进 ✅/⬜

1. 把「云图数据（已投递）」直接拖到 **面试中**（跨 2 步）
2. 期望：成功，不要求备注

### AC-3 回退必须备注 ✅/⬜

1. 聚焦或拖拽「灵犀智能（面试中）」到 **已投递**
2. 期望：弹出备注弹窗；**直接点取消** → 卡片回弹，状态不变
3. 再次拖过去 → 填「拖错列了」→ 确认
4. 期望：状态变为已投递；到详情页时间线应看到「面试中 → 已投递」并标 **回退**

### AC-4 终态规则 ✅/⬜

1. 把「云图数据」拖到 **已结束区**（如被拒）→ 要求备注，填「一面挂」
2. 再把「极光安全（已放弃）」从终态区拖回 **已投递** → 要求备注，填「企业又联系我了」
3. 期望：两次都成功；时间线上分别标 **进入终态** 与 **重新激活**
4. 尝试把「极光安全」从被拒拖到另一个终态（如已过期）→ 期望：红色提示「都是结束状态，不能互相流转」

### AC-5 幂等 ✅/⬜

1. 把已经在「已投递」的卡片再拖到「已投递」
2. 期望：不弹备注、不报错；**详情页时间线不会多出一条**

### AC-6 并发冲突 ✅/⬜

1. 打开两个标签页都在 `/jobs/board`
2. A 页把某卡从「已投递」拖到「面试中」
3. B 页（未刷新）把同一张卡从「已投递」拖到「待测评」
4. 期望：B 页显示「状态刚被别处改过（当前：面试中），已刷新」，且状态没有被覆盖

### AC-7 详情时间线 ✅/⬜

1. 打开 `/jobs` → 任意岗位「详情」
2. 期望：状态流转表单 + 时间线（倒序，含备注与标记位）+ 原始 JD

### AC-8 去重合并 ✅/⬜

1. 在 `/jobs` 复制一个已有岗位的公司 + 岗位名，去 `/jobs/new` 粘贴一段内容相同（或高度相似）的 JD 并入库
2. 期望：出现「该岗位已存在」→ 点 **合并到已有（补齐空缺字段）**
3. 期望：跳到详情页，原文出现 `【另一份重复 JD 原文】`；时间线多一条「合并重复 JD」事件

### AC-9 截止倒计时 ✅/⬜

1. `/jobs` 列表与看板卡片上都应有角标
2. 期望：`T-3 天`红、`T-5 天`黄、`T-9 天`绿、`今天截止`红、`已过期 N 天`灰、`未提供`
3. 切换「待投递」等状态筛选 → 只显示该状态岗位，且刷新后筛选保持

### AC-10 键盘可达 ✅/⬜

1. Tab 聚焦任意卡片（应有蓝色 focus 环）
2. 按 `→` / `←`
3. 期望：卡片移动到相邻列；回退方向应弹备注（与拖拽等价）
4. 终态卡片按 `←/→` 无效（需拖回非终态列）

## 6. 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 看板 401/500 或「读取岗位失败」 | 数据层没起 / 迁移没跑 | `docker compose up -d` + `node scripts/migrate.mjs` |
| 拖拽没反应 | 卡片状态是脏值（不在 13 枚举） | 看板顶部黄色提示会列出；台账改成合法状态 |
| 拖拽成功但刷新后回退 | 服务端 422（缺备注） | 看提示文案；回退必须 ≥2 字备注 |
| 页面显示英文状态（如 `to_apply`） | 旧缓存或数据脏值 | 刷新；确认 `src/lib/status.ts` 是唯一真源 |
| `verify:f08` 报「迁移计数 = 5」 | 0006 未应用 | `node scripts/migrate.mjs` 后重跑 |
| 演示数据残留 | 没清理 | `node scripts/seed-f08.mjs --clean` |
