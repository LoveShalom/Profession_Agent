## §2 待裁决

### Q-06 🔴 工时归属与 I1 膨胀

- **现状**：F-02 从 **30h 涨到 44h**（+R-1 工作区双向同步 10h、+R-3 截止三态 1h、+R-4 技能属性 3h）。
  `roadmap.md` 的 I1 预算仍是 30h，200h 总容量需重算；R-4 的差距分析（≈5h）还悬在 F-02/F-04 之间。
- **选项**：
  - **A. 接受 44h，差距分析并入 F-04（≈15h）（当前按此执行）**：I1 变长 47%，但"入库后能看到产出"闭环完整。
  - B. 砍功能换工期：把 R-1 的双向同步降级为"单向导出 + 只回读 4 列"（-5h），F-02 回到 39h。
  - C. 拆增量：把工作区整体移到 I2 之后的 F-05，F-02 回到 34h（仅 R-3/R-4 字段层）。
- **建议**：**A**。但如果你在意 I1 尽快跑通，**C 的收益最大**——工作区不是"JD 入库闭环"的必要条件，
  先让抽取+入库+预览跑通，工作区作为"产出层"后置，验收也更聚焦。
- **影响**：`roadmap.md` 增量表与容量、F-04 规范范围、I1 里程碑。

### Q-07 🟠 熟练度枚举用几级

- **现状**：R-4 暂定 5 值 `expert / proficient / familiar / basic / unknown`（精通/熟练/熟悉/了解/未标注）。
- **选项**：
  - **A. 保持 4 级 + unknown（当前设计）**：贴合 JD 原文用词（"精通">"熟练">"熟悉">"了解"），可映射权重 1.0/0.8/0.6/0.4。
  - B. 简化为 3 级：精通 / 熟练 / 了解（把"熟悉"并入"熟练"）。抽取更稳、标注更省，但丢失区分度。
  - C. 只做二元：必须 / 加分，不做熟练度。最省，但回答不了"要到什么程度"。
- **建议**：**A**。中文 JD 里"熟悉"与"熟练"确实被区分使用；若发现抽取不稳（两词混淆 >20%），再降为 B。
- **影响**：抽取 prompt、评测标注集、`job_skills.proficiency` 枚举、权重表。

### Q-08 🟠 "我的水平"从哪来（决定差距表能否成立）

- **现状**：`技能差距表` 需要"我是否具备 + 我的水平"；但 I1 没有经历库（F-03 在 I2），`experiences.skills` 为空。
- **选项**：
  - **A. `我的技能.csv` 自评（当前设计）**：工作区放一张可编辑表 `技能, 我的水平`，用户自填；工具读入计算差距。
    与"工作区可编辑"一致，零额外 UI。
  - B. 设置页勾选：结构化输入更准，但要多做一个页面。
  - C. 等经历库：F-04 先只显示"岗位要求聚合"，差距列留空到 I2 打通经历库。
- **建议**：**A**（可平滑过渡到 C：I2 起以 `experiences.skills` 为主、自评为补充）。
- **影响**：F-04 的数据来源、工作区文件数（+1 张表）、差距分可信度。

## §3 未提问项：我按以下默认执行（有异议再改）

| 决策点 | 默认处理 | 理由 |
|---|---|---|
| 无截止日期的提醒 | `absent` 时**不设截止提醒**；状态为 `to_apply` 时退化为"投递后 T+7 跟进" | 无截止时间就无倒计时；跟进提醒仍有价值，且可配置 |
| 表格中缺失值的显示 | `deadline`/`剩余天数` 留空；`text_only` 在备注列显示"原文：招满为止" | 空 = 未知，不用"未提供"污染数据列 |
| 工作区路径 | `.env` 的 `WORKSPACE_DIR`（默认 `./data/workspace`）+ 设置页可改 | 与现有 14 项环境契约一致 |
| 同步触发 | `npm run sync`；应用内改动后自动导出（不自动回读） | 回读时机由用户掌控，避免与 Excel 抢文件 |
| 技能长表编辑 | 只读；技能编辑走主表 `技能(显式)` 列 | 长表是透视视图，双向编辑会放大冲突面 |
| 推测技能熟练度 | 一律 `unknown` | 推测只能说"可能要"，不能说"要到什么程度" |
| CSV 编码与安全 | UTF-8 **带 BOM**；RFC4180 转义；`=`/`+`/`-`/`@` 开头前置 `'` | 中文乱码与 CSV 注入都是高发问题 |
| 隐含预测实现 | 规则图谱 `skill-graph.json` 打底 + LLM 补长尾 | 与 F-01 的 L0–L4 一致：可离线、可复现、可单测 |
| 评测门槛 | 显式技能 F1 ≥0.85；**误推率 ≤15%**、覆盖率 ≥60% | 误推率比命中率更关键——推错会误导学习 |
| 标注集 | `evals/skills/` 100 条，≥30 条只给领域词 | 覆盖"隐含预测"新能力 |
